# 육아고사

육아답 프로젝트의 서브 프로젝트예요. 아내가 먼저 10개의 육아 관련 질문에 답하면, 남편이 그 답을 얼마나 맞히는지 확인하는 부부 게임입니다.

## 진행 방식

1. 아내가 10문항에 답하고 제출하면 공유 링크가 생성돼요.
2. 남편이 링크를 열어 아내의 답을 하나씩 맞혀요.
3. 10문항을 모두 풀면 점수와 문항별 비교 결과를 확인할 수 있어요.

## 환경 변수

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`

Supabase의 `gosa_results` 테이블(id, name, answers jsonb, created_at)을 사용합니다.
